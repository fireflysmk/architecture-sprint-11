Домены:
 - Выделены 4 независимых домена с четкими границами
 - Каждый домен имеет свои компоненты и хранилища данных + разделение прав доступов

Потоки данных:
- Медицинские данные обрабатываются внутри своего домена
- Финансовые операции изолированы в финансовом домене
- Аналитический домен получает только агрегированные данные

Ключевые изменения:
- Шина данных (Интеграционный домен) централизует обмен между доменами
- Data Lakehouse заменяет монолитный DWH
- Четкое разделение raw-данных и аналитических данных

Преимущества:
- Нет необходимости модифицировать DWH при изменениях в бизнес-доменах
- Возможность независимого масштабирования компонентов
- Соответствие требованиям регуляторов по изоляции персональных данных
- Разделение прав доступа (RBAC например в каждом домене свои правила для роли или отдельные роли для доменов)
