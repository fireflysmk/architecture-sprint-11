# Технологический радар компании "Будущее 2.0"

## Ключевые категории технологий

### **Adopt** (Активно внедряем)
_Проверенные технологии, которые мы используем в production_

| Категория       | Технологии                          | Обоснование                          |
|-----------------|-------------------------------------|---------------------------------------|
| Хранение данных | Delta Lake, PostgreSQL              | Масштабируемость, SQL-совместимость  |
| Обработка       | Apache Spark, Python (PySpark)      | Поддержка ETL/ELT, богатая экосистема|
| Интеграция      | Kafka, gRPC                         | Высокая пропускная способность       |
| Визуализация    | Power BI (обновлённый), Superset    | Self-service аналитика                |
| Инфраструктура  | Kubernetes, Terraform               | Идемпотентность, облачная готовность |

### **Trial** (Пилотируем)
_Перспективные технологии в ограниченном использовании_

| Категория       | Технологии       | Сценарии применения               |
|-----------------|------------------|-----------------------------------|
| Хранение        | Apache Iceberg    | Альтернатива Delta Lake           |
| Обработка       | Rust              | Высоконагруженные микросервисы    |
| Методологии     | Data Mesh         | Федеративное управление данными   |

### **Assess** (Оцениваем)
_Технологии на стадии исследования_

- Google BigQuery (для отдельных аналитических сценариев)
- Flink (потоковая обработка)
- Apache Pulsar (альтернатива Kafka)
- Service Mesh (Istio)

### **Hold** (Замораживаем)
_Устаревшие технологии на выведение_

1. **MS SQL Server 2008** - неподдерживаемая версия
2. **Legacy ETL-процессы** - заменяем на Spark
3. **Apache Camel** - переход на Kafka
4. **Монолитная архитектура** - переход на DDD

## Методологический радар

### Рекомендуемые подходы:
- **Domain-Driven Design** - для четкого разделения доменов
- **Event-Driven Architecture** - основа интеграции
- **Data Product Mindset** - данные как продукты

###  Наблюдаемые тренды:
- Data Contracts
- FinOps для управления cloud costs
- AI Governance

### Устаревающие:
- Централизованный DWH как единственный источник истины
- Waterfall-подход к управлению данными
